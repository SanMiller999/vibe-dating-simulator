# Vibe Dating Simulator — v0.1.0

Первый прототип расширения SillyTavern.

## Что уже работает

- окно Vibe внутри SillyTavern;
- лента анкет;
- пропуск анкеты;
- лайк;
- автоматический тестовый match;
- список чатов;
- переписка;
- простые уведомления;
- профиль игрока-заглушка.

## Установка локально

1. Открой папку установки SillyTavern.
2. Перейди в:
   `public/scripts/extensions/third-party/`
3. Создай папку:
   `vibe-dating-simulator`
4. Распакуй туда содержимое этого архива.
5. Перезапусти SillyTavern.
6. Открой меню Extensions (иконка со сложенными блоками).
7. Найди `Vibe Dating Simulator`.
8. Нажми `Открыть Vibe`.
