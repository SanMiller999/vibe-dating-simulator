# Expectation / Discrepancy / Revelation

A Vibe public profile is not guaranteed to match the character's true/internal persona.

Layers:

Public Profile
→ Player Expectation
→ True Persona
→ Discrepancy Registry
→ Discovery
→ Emotional Reaction
→ Relationship State

NPCs may be honest, flattering, incomplete or deceptive.

Not every character lies. Not every discrepancy is revealed.

Discovery in the current release can happen through message thresholds and direct personal questions. Photo/meeting/roleplay/environment/other-NPC discovery hooks remain future extension points.

A discrepancy has severity and discoverability.

A revelation can produce:
- surprise
- curiosity
- amusement
- disappointment
- suspicion
- anger
- embarrassment
- betrayal
- attraction/trust changes

The AI receives only what the character should know. Hidden values remain hidden until the simulation marks them as discovered.

No mechanical "LIAR DETECTED" message should be shown to the player.
